# 🚗 Automobile Insurance Complaints Rankings & Premium Trend Analysis

## 📌 Project Overview

This project analyzes automobile insurance complaint data and premium trends for insurance companies operating in New York State.

The main objective is to identify complaint patterns, analyze complaint ratios, understand premium trends, compare insurance companies, and provide data-driven recommendations for improving customer service and business performance.

The project uses **SQL for data extraction and analysis** and **Power BI for interactive dashboard development**.

---

## 🎯 Project Objectives

- Analyze different types of insurance complaints.
- Identify complaint trends across different years.
- Analyze complaint ratios and company rankings.
- Study premium trends over time.
- Identify factors that may influence premium fluctuations.
- Compare the performance of five insurance companies.
- Develop an interactive Power BI dashboard.
- Generate actionable business insights and recommendations.

---

## 📊 Dataset Description

The dataset contains automobile insurance complaint and premium information for companies operating in New York State.

### Main Attributes

| Column | Description |
|---|---|
| NAIC | National Association of Insurance Commissioners ID |
| Company Name | Name of the insurance company |
| Ratio | Complaint ratio |
| Upheld Complaints | Number of complaints upheld after investigation |
| Question of Fact Complaints | Complaints requiring further investigation |
| Not Upheld Complaints | Complaints that were not upheld or withdrawn |
| Total Complaints | Total number of complaints |
| Premiums Written | Premium amount written in millions |
| Rank | Company ranking |
| Filing Year | Year in which the complaint was closed |
